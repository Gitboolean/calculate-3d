### Stage 2

- **[R2-3] `BEGIN IMMEDIATE` on every transaction escapes SQLAlchemy and breaks health** —
  `backend/src/calculate3d/core/db.py:33-36,42`, `modules/health/repo.py:18`; CLAUDE.md health
  exception. The `begin` listener calls the driver directly, so a lock/read-only failure surfaces as
  raw `sqlite3.OperationalError` (not `SQLAlchemyError`); the health ping also takes the write lock.
  Reproduced: another connection holding `BEGIN IMMEDIATE` → `GET /api/health` and
  `GET /api/pricing/plastics` return 500 after ~5 s. — **Fix now (T32):** issue the lock through
  SQLAlchemy so errors are wrapped, let the ping skip the eager lock, test with a lock held from a
  second connection → `db: "down"`.
- **[R2-4] A name that grows under NFC passes input validation and fails the response model (500)** —
  `backend/src/calculate3d/core/schemas.py:11-29`, `core/text.py:15-23`, surfacing at
  `modules/pricing/service.py:41` (same for catalog). `"̈́" * 100` → 500 `string_too_long`
  instead of 422. — **Fix now (T33):** normalise before measuring length; test with U+0344.
- **[R2-8] No regression test for evicting cached prices after a settings save** —
  `web/src/entities/price-settings/api/price-settings.ts:23-26`; AC-06, AC-13. — **Fix now (T35).**
- **[R2-9] Empty-state text shown over placeholder data** — `web/src/pages/catalog/ui/CatalogPage.tsx:46-51`,
  `web/src/entities/item/api/items.ts:23`; AC-12. `/catalog?q=xyz` (no matches) → clear search shows
  «Каталог порожній» until the uncached fetch resolves. — **Fix now (T35):** hide the empty state
  while `isPlaceholderData`; test empty result → uncached query.
