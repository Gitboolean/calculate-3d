### Stage 2

- **[R4-6] Client trims names unlike the server** —
  `web/src/shared/lib/normalize-name.ts:9`; AC-02, AC-11. `normalize('NFC').trim()` strips JS
  whitespace only; `core/text.py::normalize_name` also strips Cf and Python-`isspace()` characters
  at the edges (U+200B, U+00AD, U+2060, U+001C–U+001F, U+0085). 100 letters + trailing U+200B →
  client 101, blocked as «не довше 100 символів», server would accept 100; a name of only U+200B
  passes the client's required check and returns a generic 422. (Reviewer C; A noted.) —
  **Fix now (T44).**
- **[R4-7] Oversized minutes show two messages** —
  `web/src/features/quote-form/model/parse.ts:46,84`; AC-07. `too_large` minutes → `Infinity` →
  total-time check also fires: «Хвилини — ціле число від 0 до 59» + «Час друку — не більше
  100 000 год». Pre-existing for `6000001`. — **Fix now (T45):** run total-time checks only when
  hours and minutes are valid.
