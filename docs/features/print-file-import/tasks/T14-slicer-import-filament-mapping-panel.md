# T14 — features/slicer-import: список філаментів, вибір пластику, підтвердження сумування

## Why

Flow 5 [sad.md](../sad.md) §6 і §4 «UI-architecture». AC-02 (показати пластину), AC-07 (показати філамент і попросити обрати), AC-09 (не показувати донат), AC-09b (немає потрібного пластику), AC-10 (питати про сумування) у [PRD §5](../PRD.md).

## What

- `model/state.ts`: стан імпорту на екрані (розібраний файл, вибір пластиків, підтверджені злиття) — лише в пам'яті, зникає після збереження / скасування / перезавантаження (AC-09b).
- `ui/FilamentMappingPanel.tsx`: таблиця (`table`) філаментів — назва й тип як текст, зразок кольору з нормалізованого `#RRGGBB`, грами з мг; `select` пластику (з `entities/plastic`), підставлений пластик позначено; повідомлення «оберіть пластик для: …» поки є `unmapped`.
- `ui/MergeConfirmDialog.tsx`: на `merge-conflict` з `compose` — показує обидва філаменти, дії «Сумувати» / «Обрати інший пластик» (`dialog` з T11 або `alert-dialog`).
- Порожній список пластиків → пояснення «спершу додайте пластик у налаштуваннях цін; файл доведеться завантажити знову» (AC-09b).

## Definition of Done

> Vitest-тести панелі показують філамент як у слайсері (назва, тип, зразок кольору, грами) з Select пластику, блок доната до вибору кожного пластику, пояснення AC-09b за порожніх пластиків, діалог сумування для двох різних пар на один пластик і номер та назву імпортованої пластини.

- [ ] Тест: `plastic_id: null` → Select і текст «оберіть пластик», колбек готових рядків не викликається (AC-09)
- [ ] Тест: два різні філаменти → один пластик → діалог; «Сумувати» дає один рядок і обидва зіставлення на той пластик (AC-10)
- [ ] Тест: назва `<img onerror=…>` рендериться як текст; пластина «1 · mini christmas tree» видима (AC-02)
- [ ] `make web-check` зелений
